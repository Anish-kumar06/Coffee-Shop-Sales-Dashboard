# ☕ Coffee Shop Sales Dashboard

## 📊 Project Overview

The **Coffee Shop Sales Dashboard** is an interactive data analytics project designed to analyze coffee shop sales performance and uncover meaningful business insights.

The dashboard provides a clear overview of **total sales, order volume, product performance, customer purchasing patterns, and sales trends**. It helps business owners and decision-makers understand which products and categories contribute most to revenue and identify sales opportunities.

---

## 🎯 Project Objectives

- Analyze overall coffee shop sales performance
- Track total revenue and number of orders
- Identify top-selling products
- Analyze sales by product category
- Understand daily and monthly sales trends
- Compare sales performance across different periods
- Identify peak sales hours
- Analyze customer purchasing behavior
- Build an interactive and easy-to-understand dashboard

## 📁 Dataset

The dataset contains coffee shop transaction-level sales information, including fields such as:

- Transaction ID
- Transaction Date
- Transaction Time
- Product Category
- Product Type
- Product Name
- Quantity Sold
- Unit Price
- Total Sales
- Store/Location information

> **Note:** Dataset structure may vary depending on the source dataset used for this project.

---

## 🧹 Data Cleaning & Preparation

The raw dataset was prepared before creating the dashboard.

### Steps performed:

1. Removed duplicate records
2. Checked and handled missing values
3. Corrected data types
4. Formatted date and time fields
5. Created calculated sales metrics
6. Standardized product/category names
7. Created additional date-related fields
8. Validated the cleaned dataset

---

## 📈 Key KPIs

The dashboard tracks important business KPIs such as:

| KPI | Description |
|---|---|
| 💰 Total Sales | Overall revenue generated |
| 🧾 Total Orders | Total number of transactions |
| ☕ Units Sold | Total quantity of products sold |
| 💵 Average Order Value | Average revenue per order |
| 🏆 Top Product | Highest-performing product |
| 📅 Best Sales Day | Day with highest sales |
| ⏰ Peak Sales Hour | Hour with maximum transactions |

## 📊 Dashboard Features

### 1. Sales Overview
Provides a high-level view of overall business performance.

### 2. Sales Trend Analysis
Shows how sales change over:

- Daily
- Weekly
- Monthly
- Yearly periods

### 3. Product Analysis
Identifies:

- Best-selling products
- Lowest-performing products

- Hour

- Month

Compares revenue and quantity sold across different coffee shop categories.

- Month
- Product Category
- Product Type
- Product
- Store/Location
